        Javascript - Event and Profile modules

        In this 20-minute JavaScript code walkthrough, I take a look at two new modules I've added to my Task Master application: the Event Module and Profile Module.

        Task Master is a vanilla JavaScript task-management application that stores task data as JSON in localStorage. Rather than creating separate sets of data for each new feature, these modules reuse the existing Task Master data and present it in new ways.

        The Event Module retrieves tasks stored by Task Master and displays them as events, allowing existing task information to become part of a broader event-management interface.

        The Profile Module takes this concept a step further by allowing tasks to be associated with individual profiles. This creates a relationship between people and tasks while continuing to work from the same locally stored data.
